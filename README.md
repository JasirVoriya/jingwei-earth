如果把时间拖到 **1942 年**，再转动地球，你会看到什么？

从欧洲到北非，再到太平洋，原本分散在课本章节中的地点，开始出现在同一个世界里。点击战役节点，读懂这一年发生了什么；沿着方向动画观察地域联系，再把时间向前推一年。

**经纬**是一款中文地理与近现代战争史学习工具。它把可旋转的地球、年度历史节点和简明知识卡放在一起，让你一边探索空间，一边建立时间线索。

> **1756—1991** 年时间轴 · **19** 个代表性战争专题 · **177** 个国家／地区制图单元 · **17** 个地理要点 · **12** 道带解析的知识题

## 功能一览

| 玩法 | 你可以做什么 |
| --- | --- |
| 🌍 把地球握在手中 | 自由旋转、滚轮缩放、双指缩放；点击国家，查看地理卡片与相关历史 |
| ⏳ 拖动时间，看见变化 | 按年查看战争节点；自动播放，支持 1× / 2× / 4× 速度 |
| ✨ 让历史在地图上发生 | 查看动态方向弧线、当年战事与政治／停战节点；按需保留此前事件 |
| 🔎 专注一场战争 | 将时间轴缩到当前战争，点击年份切换阶段，开启镜头跟随 |
| 🧭 从地理理解历史 | 探索海峡、山脉、河流与大洋，思考交通、距离和补给的影响 |
| 📖 建立自己的学习记录 | 收藏地点与专题、标记已学、用即时解析测验巩固知识 |

第一次世界大战、第二次世界大战和朝鲜战争提供了扩展的逐年叙述。其他专题以代表性节点为主；未收录具体战役的年份会明确提示，不把资料空白呈现成“没有战争”。

## 三分钟体验

1. **先看空间。** 拖动地球，找到欧洲、北非和太平洋，感受战场之间的距离。
2. **再看时间。** 选择“第二次世界大战”，点击“聚焦当前战争”，将时间拖到 **1942**。
3. **让画面动起来。** 开启行动方向与镜头跟随，点击播放，观察不同年份的节点与叙述。
4. **追问一个为什么。** 进入地理探索，查看苏伊士运河，看看海上通道怎样连接地理与历史。
5. **检验记忆。** 进入“知识挑战”，答一道题，再通过“地图复习”回到对应地点。

## 快速开始

这是一个**纯静态网站**：没有后端、数据库或 API Key，也无需安装前端依赖。Three.js、地图与学习数据均随项目提供，运行时不依赖外部 JavaScript CDN。

克隆仓库后，在项目根目录启动：

```bash
git clone https://github.com/JasirVoriya/jingwei-earth.git
cd jingwei-earth
python3 -m http.server 8080 --directory dist
```

然后打开 **http://localhost:8080**。

也可以使用 VS Code Live Server 或其他静态服务器，将网站根目录指向 `dist/`。

> 请通过 HTTP 服务器访问。直接双击 `index.html` 使用 `file://` 打开，可能因浏览器的 ES 模块限制而无法运行。

## 为什么容易运行、也容易改

- **原生 HTML / CSS / JavaScript**：无需构建工具，修改文件即可预览。
- **双渲染路径**：优先使用 Three.js WebGL；设备无法创建 WebGL 上下文时，自动切换到 Canvas 球面渲染，保留旋转、缩放和历史图层。
- **内容与交互分离**：战争、地理要点和测验集中在数据文件中，方便补充资料。
- **浏览器本地记录**：收藏、已学专题与测验最高分保存在 localStorage，不需要登录；记录不会自动跨设备同步。
- **兼顾不同屏幕**：提供桌面与手机布局，并尊重系统减少动态效果的偏好。

| 文件 | 职责 |
| --- | --- |
| `dist/index.html` | 应用入口 |
| `dist/app.js` | 时间轴、筛选、知识卡与学习记录 |
| `dist/globe.js` | Three.js 地球与动画 |
| `dist/globe-canvas.js` | 无 WebGL 时的兼容球面渲染 |
| `dist/globe-math.mjs` | 经纬度转换与球面弧线计算 |
| `dist/content.js` | 战争专题、地理要点与测验 |
| `dist/campaigns.js` | 逐年叙述、事件与行动方向 |
| `dist/map-data.js` | Natural Earth 地图数据 |
| `tests/` | 数据与核心逻辑检查 |

## 测试

安装 Node.js 20 或更高版本后，在项目根目录运行：

```bash
node --test tests/*.test.mjs
```

当前包含 **13 项自动化检查**，覆盖日期与坐标、搜索筛选、题目关联、经纬度转换、跨日期变更线弧线、年度事件过滤与战争阶段完整性。

浏览器检查已覆盖兼容渲染、拖动缩放、时间轴、图层开关、播放终点、搜索、答题和 390px 窄屏布局。测试浏览器禁用了 WebGL，因此 GPU 渲染路径尚未在该环境完成视觉验证；实体设备双指触控仍需进一步验证。

## 数据与史实说明

经纬是一个学习入口，阅读资料与核对历史仍然是体验的一部分。

- **专题范围**：收录 1756—1991 年间的代表性战争，并非完整全球战争数据库。战争起止分期可能因叙述口径不同而异。
- **时间粒度**：按年汇总全年事件，不代表某一天同时发生的形势；未覆盖逐月战线变化。
- **动画含义**：弧线表示行动大方向，不是精确行军轨迹、前线或实际控制区。动画速度、点的大小和闪动不表示伤亡或战斗强度。
- **地图底图**：采用当代边界帮助定位，相关区域高亮不代表历史疆界、完整参战国范围或主权立场。
- **资料来源**：`content.js` 与 `campaigns.js` 保留博物馆、档案与历史资料页面链接，应用内也可打开参考资料。原因与地理影响属于简要综合解释。
- **制图精度**：Natural Earth 1:110m 数据可能省略小国与岛屿；首都标签可能不完整或滞后。地理要点是近似定位，不表示完整地形范围。
